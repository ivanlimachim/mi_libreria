# mi_libreria
Repositorio para tecnologías en internet.
Página en desarrollo para la materia de tecnologías de internet.
Página para una librería dirigida al público en general, donde los mismos podrán explorar el catálogo de libros disponibles a la venta en la librería. En la página se podrá consultar información de los libros, como el título, autor, género, descripción, precio y disponibilidad, está página permitirá que el público en general pueda conocer los libros en venta, permitiendo así tener un mayor alcance.
