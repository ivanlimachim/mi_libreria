# mi_libreria
Repositorio para tecnologías en internet.
Página en desarrollo para la materia de tecnologías de internet.
Página para un libreríam dirigda al público en general, donde los mismos podrán explorar el catálogo de libros disponibles a la venta. En la página se podrá consultar información de los libros, como el título, autor, género, descripción, precio y disponibilidad.
